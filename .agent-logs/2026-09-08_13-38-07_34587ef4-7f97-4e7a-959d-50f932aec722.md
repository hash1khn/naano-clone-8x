For this app, **`lucide-react` is the better fit**.

| | `react-icons` | `lucide-react` |
|---|---|---|
| Bundle | Pulls from a huge multi-set package; easy to import more than you need | Tree-shakes cleanly; one icon family |
| API | Generic (`size`, etc.) | First-class Lucide props (`strokeWidth`, `absoluteStrokeWidth`) |
| Maintenance | One meta-package wrapping many sets | Same icons, maintained as the Lucide React SDK |

You only need Lucide-style stroke icons for the sidebar, so `lucide-react` is lighter and more intentional. Keep `react-icons` if you’ll mix Material, Font Awesome, Heroicons, etc. in one app.

I can switch the sidebar to `lucide-react` if you want.
